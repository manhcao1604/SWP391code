🔌 BACKEND INTEGRATION
================================================================================

Frontend connects to backend API at:
    http://localhost:8080

Before running frontend, ensure:
1. Spring Boot backend is running
2. Backend is on port 8080
3. Database is configured and running

Configure in .env.local:
    VITE_API_BASE_URL=http://localhost:8080

================================================================================
🐛 TROUBLESHOOTING
================================================================================

Issue: Port 5173 already in use
Solution: npm run dev -- --port 3000

Issue: npm: command not found
Solution: Restart VS Code or restart computer

Issue: White blank page
Solution: Press F12 to check console, restart npm run dev

Issue: Cannot connect to backend
Solution: Verify backend running on port 8080

Issue: Changes not showing
Solution: Stop server (Ctrl+C) and restart (npm run dev)

More details in: VSCODE_SETUP_GUIDE.md
